# 多機能文章生成ツール（Pollinations対応）

キーワードや条件を指定すると、無料API（Pollinations）を使って文章を生成するWebアプリです。  
リアルタイムで文章を作成し、保存や修正も可能です。

---

## 🌐 公開URL
[アクセスはこちら](https://my-fifth-portfolio-bsu4-mul4c5wbn-8air28s-projects.vercel.app)

---

## 💡 主な機能
- キーワード指定による文章生成
- 言語、トーン、長さ、出力形式の選択
- 追加指示による文章の調整
- 生成結果の履歴保存と再利用
- 生成結果のコピー・保存・修正・キャンセル
- 連続生成（同時複数タスク対応）

---

## 🛠 使用技術
- HTML / CSS / JavaScript
- Node.js / Express
- Pollinations API
- Vercel（デプロイ）
